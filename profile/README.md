## ❓ FAQ

### Do I need to run it as Administrator?

Most users can install and run the application with normal permissions. Follow the official troubleshooting instructions if your installation requires additional permissions.

### Does Hearthstone Deck Tracker show cards in my opponent's hand?

It records cards played and estimates certain opponent-hand information based on available game data. It does not reveal information that is genuinely hidden from the player.

### Can I import and export decks?

Yes. The Deck Manager supports importing and exporting deck lists using supported sources and formats.

### Does it support an in-game overlay?

Yes. The application provides an overlay for displaying tracking information, with additional display options available.

### Are plugins still supported?

HearthSim announced that plugin support is scheduled to end on November 30, 2026. Check the official announcement for details about affected plugins and features being integrated into the main application.
